# Segment-Tree
DSA Extended Assignment - Semester 241

# Project description
Segment Tree is a versatile data structure allowing efficient querying, updating intervals of array. It is commonly used in image processing, range-based statistic, and competetive programming. 

In this project, I implement segment tree with basic operations such as min, max, sum, multiplication; then visualize it on the terminal

## How to set up
YOu can download the cpp file and run it in built-in C++ workplace, or copy the content of the file and run it on onlien c++ compiler
